# Practical assessment checklist

The ITS evaluator completes this on a tablet while the learner operates a counterbalance forklift. Each item is marked Pass or Fail. Failing any item marked **Critical** fails the whole assessment; failing more than 3 other items also fails it (*proposed*). Draft for ITS inspector review.

| # | Section | The learner… | Critical |
| --- | --- | --- | --- |
| 1 | Pre-use inspection | Checks forks, chains, mast and backrest for damage | Yes |
| 2 | Pre-use inspection | Checks for hydraulic, oil and fuel leaks | Yes |
| 3 | Pre-use inspection | Checks tyres, overhead guard and that the data plate is legible |  |
| 4 | Pre-use inspection | Checks fluid levels, or battery and connectors, or LPG cylinder and fittings |  |
| 5 | Pre-use inspection | Tests horn, lights, alarm, brakes, parking brake and steering | Yes |
| 6 | Pre-use inspection | Tests lift, lower and tilt controls |  |
| 7 | Pre-use inspection | Records the check and states what to do with a defect |  |
| 8 | Mounting and start | Mounts using three points of contact; adjusts seat and mirrors |  |
| 9 | Mounting and start | Fastens seat belt before moving | Yes |
| 10 | Travel | Looks all around before moving; travels at a safe speed |  |
| 11 | Travel | Looks in the direction of travel, forward and reverse | Yes |
| 12 | Travel | Slows and sounds horn at corners, doors and intersections |  |
| 13 | Travel | Keeps a safe distance from pedestrians and stops when needed | Yes |
| 14 | Travel | Allows for rear-end swing when turning |  |
| 15 | Load handling | Checks load weight against capacity before lifting | Yes |
| 16 | Load handling | Approaches square; sets fork spread for the load |  |
| 17 | Load handling | Inserts forks fully; load against backrest |  |
| 18 | Load handling | Lifts slightly, tilts back, travels with load low | Yes |
| 19 | Load handling | Checks overhead clearance before raising |  |
| 20 | Stacking | Stops before the stack; raises only when stationary | Yes |
| 21 | Stacking | Tilts forward only when the load is over the stack; places and withdraws smoothly |  |
| 22 | Stacking | Lowers forks before moving away |  |
| 23 | Ramp (if available) | Keeps the load uphill; does not turn on the slope | Yes |
| 24 | Parking | Parks in a safe place, not blocking exits or equipment |  |
| 25 | Parking | Forks lowered, neutral, parking brake on, engine off, key removed | Yes |
| 26 | General | Never lets anyone stand under raised forks or ride on the truck | Yes |

**Record for each assessment:** learner name and ID, forklift type and capacity, location, date, result (Pass / Fail), evaluator notes, evaluator name and signature.
